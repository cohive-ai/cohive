# Languages and maintainers

[中文说明](#中文)

Cohive's interface, CLI, MCP tool descriptions and chat notifications are translated. English is the source language. How to add or maintain a language: [CONTRIBUTING.md → Languages and translations](../../CONTRIBUTING.md#languages-and-translations).

| Language | Code | Status | Maintainers |
|---|---|---|---|
| English | `en` | Built-in, source language | Core team |
| 简体中文 (Simplified Chinese) | `zh-CN` | Built-in | Core team |

Status values:

- **Built-in**: maintained by the core team; every change must include it, and tests require it to be complete.
- **Community**: maintained by the people listed; missing strings fall back to English.
- **Incomplete**: community language without an active maintainer, or with large gaps.

To add a row, follow the steps in CONTRIBUTING and list yourself with your GitHub handle (for example `@octocat`). Translators who contributed substantially may be listed next to the maintainers.

## 中文

Cohive 的界面、命令行、MCP 工具说明和群通知都可以翻译，英文是翻译基准。英文、简体中文由核心团队维护，测试要求两者完整；其他语言由社区维护，表中列出的维护者负责审核该语言的修改，缺词时显示英文。新增或认领一种语言的步骤见 [CONTRIBUTING.zh-CN.md](../../CONTRIBUTING.zh-CN.md)。

**额外加的守卫，为 THEME-1 铺路**：`web/src/theme.guard.test.ts` 扫描 `web/src` 全部非测试源码，以下写法一律报错：

- 写死的十六进制色、`rgb()` / `hsl()`；
- Tailwind 调色板色，例如 `bg-blue-500`；
- `bg-white`、`text-black` 这类白和黑；

品牌标志Brand mark

一枚六边形，缺了右边一条边。它是蜂巢，也是字母 C；缺口里的黄色格子，是正在接进来的那个智能体。A hexagon missing its right edge — a hive cell and a letter C. The yellow cell in the opening is the agent plugging in.

构思Concept

三层意思，一个形状Three ideas, one shape

开口的蜂巢 = COpen cell = C

六边形是 hive 的直接隐喻。去掉右边一条边，它同时读作 Cohive 的 C，也表示协作层对外开放、可以自托管接入。The hexagon is the hive. Remove one edge and it reads as the C of Cohive — an open layer anyone can self-host and plug into.

白格是人，黄格是智能体White is the person, yellow the agent

两枚格子并排，大小相同，但颜色有主次：人在内侧拍板，智能体在外侧干活。对应「智能体递单，人来拍板」。Two equal cells, different roles: the person sits inside and decides, the agent sits at the edge and does the work.

黄格落在缺口Yellow sits at the gap

黄格正对缺口，像刚从外面接进来，指每个人各自的 Claude Code、Codex 经远程 MCP 接入。The yellow cell faces the gap as if it just docked — each teammate's own Claude Code or Codex joining over remote MCP.

结构Construction

全部是直线和 60° 角Straight lines and 60° angles only

标志和字标都由几何图形画成，没有一个字依赖字体文件。所以 SVG 可以直接放进 GitHub 的 README，不会因为字体被屏蔽而变形。Mark and wordmark are pure geometry — no glyph depends on a font file, so the SVG drops straight into a GitHub README.

尺寸与安全距离Size & clear space

16 像素也能认出Legible down to 16px

四周至少留出标志宽度的四分之一。标志最小 16 像素；字标最小 72 像素宽，组合版缩到字标不够 72 像素时只用标志。Keep at least ¼ of the mark's width clear on every side. The mark needs at least 16px; the wordmark at least 72px wide. Where a lockup would make it narrower, use the mark alone.

使用规范Usage

四条要做，四条别做Four do's, four don'ts

深色底上用标准版Use the primary on dark
浅色底换黑框黑格Switch to black on light
四周留足安全距离Keep the clear space
只能单色时整体同色One color means all one color
不要旋转，缺口永远朝右Don't rotate — the gap faces right
不要把外框涂成黄色Don't make the frame yellow
不要交换人和智能体的颜色Don't swap person and agent colors
不要拉伸变形Don't stretch it
